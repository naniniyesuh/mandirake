# MANDIRAKE

Yoğurt kavanozu ve anne sütü (buzluk) stok takip uygulaması. SwiftUI, iOS 17+.

- `mandirake/` — Swift kaynak dosyaları ve Assets (Xcode projesinin kaynak klasörü)
- `AppIcon-1024.png` — uygulama ikonu

- `mandirake.xcodeproj` — Xcode projesi
- `docs/` — alpp.studio sitesi (GitHub Pages)
- `store/` — App Store metinleri
